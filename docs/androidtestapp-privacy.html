개인정보처리방침 — 안드로이드 개발 테스트앱

최종 수정일: 2026년 9월 17일 · 앱 패키지: com.sgshs.pilot.androidtestapp1

「안드로이드 개발 테스트앱」(이하 '본 앱')은 안드로이드 UI 구성을 테스트해 보기 위한 예제 모음 앱이며, 별도의 서비스 기능을 제공하지 않습니다. 본 앱은 이용자의 개인정보를 수집·저장·전송하지 않습니다.

1. 수집하는 개인정보

본 앱은 어떠한 개인정보도 수집하지 않습니다. 회원가입·로그인이 없으며, 이름·이메일·전화번호·위치정보·기기 식별자·광고 식별자 등을 요구하거나 저장하지 않습니다. 예제 화면에 입력하는 값(숫자, 이름 등)은 해당 화면에서만 사용되고 기기 밖으로 전송되거나 보관되지 않습니다.

2. 권한 사용

본 앱은 웹 화면 예제를 표시하기 위한 인터넷 접속 권한(INTERNET)만 사용합니다. 위치·카메라·연락처·문자(SMS)·저장소 등 개인정보와 관련된 권한은 요청하지 않습니다.

3. 외부 화면으로의 연결

  • 웹 화면 예제: 예제 화면 안에서 외부 웹사이트(예: 다음 모바일)를 표시합니다. 해당 사이트 이용 중 전송되는 정보는 그 사이트의 개인정보처리방침을 따르며, 본 앱 개발자는 이를 수집하거나 열람하지 않습니다.
  • 문자 보내기 예제: 이용자가 버튼을 누르면 기기의 기본 문자 앱을 엽니다. 본 앱은 문자를 직접 발송하지 않으며, 입력한 번호와 내용을 저장하거나 전송하지 않습니다. 발송 여부는 이용자가 문자 앱에서 직접 결정합니다.

4. 광고 및 분석

본 앱은 광고를 게재하지 않으며, 이용 행태를 추적하는 분석 도구를 포함하지 않습니다.

5. 아동의 개인정보

본 앱은 개인정보를 수집하지 않습니다.

6. 방침 변경

본 방침이 변경되는 경우 본 페이지를 통해 고지합니다.
